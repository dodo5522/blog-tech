## 完了した項目

### Studio 配信用 Terraform 基盤

- `infra/` を公開サイト用 + Studio 用の S3 / CloudFront 構成に再設計した
- 公開サイト用 bucket と Studio 用 bucket を別リソースとして管理するようにした
- 両 bucket は public access block 有効、CloudFront OAC 経由の private 配信前提
- CloudFront distribution も公開サイト用と Studio 用を分離した
- CloudFront Function で `/path/` と extensionless path を `index.html` に rewrite するようにした
- deploy 用 GitHub Actions IAM role に、両 bucket への sync と両 distribution への invalidation 権限を付与するようにした
- Terraform S3 backend 宣言を追加した

### Terraform outputs

以下の output を追加した。

- `site_bucket_name`
- `site_cloudfront_distribution_id`
- `site_cloudfront_domain_name`
- `site_url`
- `studio_bucket_name`
- `studio_cloudfront_distribution_id`
- `studio_cloudfront_domain_name`
- `studio_url`
- `github_actions_deploy_role_arn`

`studio_url` は `https://<studio CloudFront domain>` 形式で出力し、後続の GitHub Actions から Sanity CORS origin 設定に使う想定。

### Sanity Studio build script

- `package.json` に `sanity:build` を追加
- Studio build 出力先は `dist-studio`
- `dist-studio` を `.gitignore` に追加
- Sanity Studio build に必要な `react` / `react-dom` を dependencies に明示追加した

### Terraform 実行環境の確認

- `tfenv` で Terraform `1.15.3` を導入した
- `infra/versions.tf` の Terraform CLI 制約を `>= 1.15.0, < 2.0.0` に更新した
- `terraform init -backend=false` により `infra/.terraform.lock.hcl` を生成した
- `.terraform.lock.hcl` で AWS provider `5.100.0` が lock された
- `.terraform.lock.hcl` は Terraform CLI 本体ではなく provider version / hash を固定するものとして整理した
