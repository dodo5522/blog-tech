### fallback 依存の整理

- `SANITY_FALLBACK_MODE=auto|always|never` を追加
- `auto`: Sanity 未設定時のみ fallback を使う
- `always`: Sanity fetch 失敗時も fallback を使う。ローカルのオフライン UI 確認用
- `never`: fallback を使わない。本番 deploy 用
- `deploy.yml` は `SANITY_FALLBACK_MODE=never` に固定
- Sanity 接続済みで fetch に失敗した場合、本番 build は fallback を公開せず失敗する
- Sanity fetch の重複実行を避けるため、ビルド中の fetch 結果を query / params 単位で cache するようにした
